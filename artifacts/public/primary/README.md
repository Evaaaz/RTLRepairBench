# Anonymous VeriCodeGen supplement

This tree was generated by `benchmarks.export_vericodegen_supplement`. `inventory.json` records the SHA-256 of every private source artifact and its sanitized public derivative. The public ledger contains exact prompts, request/response metadata, candidate SHA-256 values, and terminal formal and independent-simulation verdicts. Raw provider response bodies, candidate text, credentials, local paths, repository remotes, and author identifiers are not included.

The `full85_rows.jsonl`/`clean75_rows.jsonl` and
`vericodegen_full85_rows.jsonl`/`vericodegen_clean75_rows.jsonl` pairs are
intentionally byte-identical sanitized ledgers. The clean75 cohort is selected
from that shared row source by the frozen clean75 manifest; offline
reproduction enforces byte equality so these aliases cannot silently diverge.

## Frozen protocol identity

The formal rows in this snapshot are historical records, not outputs of the
current verifier source. Their embedded `formal_protocol_sha256` is
`0ca7c6f3b5bcbc07e4a52563a5aea7ddf6fa271ea9b0b9c3270ae20774e2b59e`.
The released verifier has since added candidate-RTL security preflight,
one-way candidate-input isolation, nonce-authenticated simulator verdicts,
and stricter roster/ledger gates, so its fingerprint intentionally differs.
Do not replace the embedded historical fingerprint or mechanically relabel
these rows. A current-protocol recheck must materialize the checksum-bound
candidate/proof trees, write a new result ledger, and report every changed
verdict and denominator. Those external trees are not in this anonymous
package, so that recheck remains outstanding.
